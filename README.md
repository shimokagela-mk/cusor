# 期练

微信小程序。用来做减脂或增肌的长期计划，并把它拆成一周安排和每天的训练、饮食打卡。

## 怎么用

1. 用微信开发者工具打开仓库根目录。没有正式 AppID 时，可以用测试号。
2. 在「制定计划」里选择减脂或增肌，填写身体数据、目标、周期、训练日、场地、伤病和忌口。
3. 计划会生成三个阶段、每天的热量和蛋白质 / 碳水 / 脂肪，以及早餐、午餐、晚餐、加餐的具体菜谱。
4. 「今日」记录体重、按组完成训练，并把实际吃的食物记下来，和当天额度对比。
5. 「本周」可以调换两天的训练。没做完的日子标成未完成，后面的安排不会顺延。

饮食可以搜索食物库、从最近吃过里选、手动填写，或拍照后确认菜名和份量。家常菜、外卖和健身餐都会出现在菜谱和食物库里。

## 数据存在哪里

每个人的计划和记录用本地存储分开保存，可在「我的」里切换用户。这台手机上的数据不会自动上传。正式上线时，把 `miniprogram/services/store.js` 的存储换成微信云开发或自己的后端，并在小程序里接入微信登录。

## 食物识别

默认识别不会假装自己看懂了照片。拍下照片后，输入菜名即可匹配食物库，也可以直接点选候选。

如果要接图像识别，填写 `miniprogram/config.js` 里的 `recognizeUrl`，并运行：

```bash
npm run recognize-server
```

服务地址示例：`http://127.0.0.1:8787/api/food/recognize`。配置 `FOOD_VISION_URL`、`FOOD_VISION_API_KEY` 和可选的 `FOOD_VISION_MODEL` 后，服务会先向兼容接口询问菜名，再回到食物库核算热量。没有密钥时，仍然按你输入的菜名匹配。

## 热量怎么来的

每日热量用 Mifflin-St Jeor 基础代谢，再按每周训练天数估算维持热量。减脂做缺口，增肌做盈余，蛋白质和脂肪按当前体重估算，碳水补足剩余热量。这是训练安排用的估算，不是医疗建议。
