# 用户喜好存档（公司生活）

> 来源：制卡访谈与试玩反馈。供后续改卡/写提示词时对齐，勿当对外说明书。
> 更新：v0.6.15（表现轴立体化；粗话硬清单）

## 一句话核

**强迫 · 玩弄 · NTR · 人妻 · 女儿 · 姐姐 · 乱伦（仅成年）**

## 核心性癖（用户亲口）

1. **强迫** — 强制推进，真抵抗可压
2. **玩弄** — 遥控、把柄、比较、行程操控
3. **NTR** — 做时打电话；正常语气 vs 失控对照
4. **人妻** — 陈亦勤、丁丁主线
5. **女儿 / 乱伦** — 玩家亲生女儿**婉婷（22岁成年）**；萝莉脸反差婊；处女；有男友陆辰未实操；爱聊骚；手机大量裸自拍；路径=聊骚+裸照把柄+破处+对男友NTR
6. **姐姐** — 偏好仍在；卡内尚未独立角色（待定）

## 场景锚点

- 做时打电话（人妻丈夫 / 婉婷→陆辰）
- 公共潮吹（憋→漏→喷）
- 上班塞玩具
- 女儿线：Playbook D；翻相册；叫爸爸；处女破处过程要写紧与痛

## 权位与推进

- 玩家主导；偶发反制
- 数值 + 对话可越级
- 喜欢拖深，不要无过程散架

## 文风

- 日常冷硬；动手夸张
- 禁糊词；部位/节奏/体液硬点名
- 身材出场定型 + 动手手感；逼外形+状态
- 粗话分轨；电话 NTR 交替句
- 事后短收束具体但不恶心

## 硬边界

- 粪 / 致死 / 永久毁容 / 动物 / 致残
- **禁止未成年 / 未满21岁性内容**（婉婷钉死22；「萝莉脸」仅外形）
- 成年乱伦可写
