# 故人录

## 当前版本
v0.1.0

## 内容范围
- 主角：用户本人（约30，乡村长大）
- 玩法：时间线沙盒（回村/走亲戚/同学会/回城）+ 点名召人
- 固定故人：小妹、小娇、周雅琴、赵慧、小静、小萌、亚会、明月、朱梦婷、苏甜甜、杨阳
- 特殊：小妹只摸/玩/看不做；姐妹花亚会+明月；工作/初中模板补位
- 硬闸：可玩性描写双方≥21；童年经历不展开未成年性描写
- 文风：沿用喜好存档

## 开玩口令
`列表` `回村` `走亲戚` `同学会` `回城` `找 名字` `姐妹花` `今日`
