# 用户喜好存档（窥私 · 需求记录）

> 状态：需求分析已确认，进入世界观规模。供后续写卡对齐。  
> 更新：2026-11-15  
> 卡名：`窥私`

## 一句话核

**他人隐私 · 多人交叉 · 把柄网 · 强迫占用 · 讲述逼问**

表层是偷看/偷听/查证别人的私密；深层是据为己有，并用讲述环节把「所有隐私」逼问干净。

## 已确认主题轴

沿用既有硬口味，叠加隐私母题：

1. **强迫** — 真抵抗可压  
2. **玩弄** — 遥控、行程、比较、证物羞辱  
3. **NTR** — 做时打电话；正常语气 ↔ 失控脏句交替  
4. **人妻** — 主线之一  
5. **姐姐** — 亲姐已婚线要写（此前卡内缺口）  
6. **成年乱伦** — 可写，双方≥21  
7. **他人隐私（本卡主壳）** — 偷窥 / 偷听 / 偷拍 / 查手机 / 撞破 / 隔墙 / 监控 / 把柄  
8. **多人隐私交叉** — 几条线同时握在手里，彼此不知或半知，串线时最好玩  
9. **讲述环节（本轮新增·高优先）** — 喜欢**问**她们的隐私；要**所有**隐私，不只身体反应

## 讲述环节（定稿意向）

用户主导提问，角色必须回答；不是可省略的旁白。

### 问什么（「所有隐私」覆盖面）

- **身体隐私**：第一次、频率、会不会潮喷、敏感点、能否失禁边缘、现在逼里什么状态  
- **婚姻/恋爱隐私**：和丈夫/男友怎么做、喜欢什么体位、有没有偷情念头、高潮时叫谁  
- **影像/设备隐私**：相册、已删、云盘、检索记录、定位、门锁记录  
- **空间隐私**：洗澡习惯、门是否关严、隔墙知不知道自己叫出声  
- **关系隐私**：对姐姐/同事/邻居的真实评价、有没有互相发过私密  
- **对照隐私**：被问时用你已掌握的证据对质；撒谎就加码逼问  

### 怎么问（形式）

- 纯口述审讯：按清单一项项问，不准糊弄  
- 边做边问：顶一下逼问一句；答不清就停/加深  
- 电话里问：丈夫在听筒另一端时，用气声回答你、对丈夫说假话  
- 交叉问：拿 A 的隐私问 B；逼 A 讲述 B 的事（或念 B 的聊天）  
- 复述验收：讲完强迫她用脏话复述要点，写入把柄/纪要  

### 讲述时的脏度

- 禁止「还好 / 正常 / 不记得」空答  
- 必须点名部位、次数、和谁、在哪、有没有射进去/潮了没有  
- 讲述可触发当场身体反应（说到丈夫时穴绞一下等）  
- 与文风总则一致：禁糊词；叙述也脏

### B. 城市随机遇人（2026-11-15 用户追加）

固定团之外，需要**可生成的路人/偶遇层**：地铁上看到的、小区里遇到的、街上/商场等。  
用途：补「他人隐私」的广度——一眼窥见、短线取证、可讲述、可升格进浅残留/把柄；默认不抢固定团主线。

| 池 | 例 | 隐私撞法 |
|----|----|----------|
| 地铁/公交 | 对座睡着露、耳机外放私密通话、手机亮屏被瞥见 | 偷窥屏/偷听 → 可选跟丢或同站下车再撞 |
| 小区公共 | 快递柜、地下车库、垃圾房、健身区、门禁大厅 | 猫眼式路过、监控回放、管家/邻居闲话 |
| 街头/商场 | 试衣间外、卫生间排队、咖啡馆屏 | 短线窥视；难追则只取证不深挖 |
| 升格规则 | 同一随机人第2次出场或用户点名「留她」 | 写入重要角色/浅残留，可进讲述与串线 |

口令意向追加：`地铁` `街头` `小区逛` `随机` / `今日路人`；生成时必须≥21，给临时名+一句话隐私锚+反制芽。

## 脏玩阶段梯（已定意向）

无意撞见 → 故意再看 → 取证 → 对质强迫 → 讲述逼问（可穿插全程）→ 占用身体 + 电话NTR → 半公开/近暴露 → 串线升级

## 文风与硬边界（沿用）

- 日常可冷硬；动手写满过程（升温/抽插/高潮）  
- 禁糊词；部位/体液硬点名；粗话分人配额  
- 活人感：有效反制、事后翻脸；禁整场全配合  
- **禁止**：粪 / 致死 / 毁容 / 动物 / 致残；**<21 性描写**；幼童入性戏  
- 成年乱伦可写
