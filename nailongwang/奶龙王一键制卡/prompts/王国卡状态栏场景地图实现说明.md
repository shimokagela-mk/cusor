# 阿斯特里亚王国状态栏场景地图实现说明

> 目标：让其他 AI 在不修改本体状态栏文件的前提下，理解并复现「王国卡」状态栏里的场景地图。
>
> 本文件只总结现有实现，不参与运行，不替换 `frontend/status-bar.html` 或 release 文件。

地图依赖的运行时状态集中在全局对象 `D`：

```js
var D={
  equip:[],
  skills:[],
  inv:[],
  chars:[],
  sceneChars:[],
  quests:[],
  mapEls:[],
  loc:'圣城奥拉提姆'

```

`loadAll()` 会读取以下表格并刷新地图相关数据：

- `sheet_GlobalData` / `全局数据表`：读取 `当前地点` 到 `D.loc`。
- `sheet_Characters` / `重要角色表`：读取重要角色到 `D.chars`。
- `sheet_SceneNPC` / `在场临时角色表`：读取临时在场角色到 `D.sceneChars`。
- `sheet_MapElements` / `地图元素表`：读取地图元素到 `D.mapEls`。

其中地图最关键的是：

```js
var me=getSheet(d,'sheet_MapElements','地图元素表');
D.mapEls=me?rowsOf(me):[];
renderMapList();
if(!mapCache[D.loc]&&!mapBusy){doMap(false)}
```

也就是说：数据加载后会先渲染右侧列表，再在当前地点没有缓存且没有正在生成时自动生成地图。

## 4. 地图元素表结构

`sheet_MapElements` 是场景地图最稳定的数据源。表格模板定义如下：

| 列名 | 含义 |
|---|---|
| row_id | 行号 |
| 元素名称 | 地图上显示的角色、地点、障碍物、出口等名称 |
| 元素类型 | 主角 / 友方 / 敌方 / NPC / 地标 / 障碍物 / 出口 |
| X坐标 | SVG X 坐标，范围 0-800 |
| Y坐标 | SVG Y 坐标，范围 0-600 |
| 状态 | 元素当前状态 |
| 描述 | 弹窗显示描述 |
| 所属区域 | 地标所属区域 |
| 传说背景 | 地标背景信息 |

DDL 语义等价于：

```sql
CREATE TABLE map_elements (
  row_id INTEGER PRIMARY KEY AUTOINCREMENT,
  element_name TEXT NOT NULL,
  element_type TEXT NOT NULL,
  pos_x TEXT,
  pos_y TEXT,
  element_status TEXT,
  element_desc TEXT,
  region TEXT,
  legend TEXT
);
```

但导出到状态栏后，`rowsOf()` 会按中文表头生成对象，所以前端实际访问字段是：

```js
el['元素名称']
el['元素类型']
el['X坐标']
el['Y坐标']
el['状态']
el['描述']
el['所属区域']
el['传说背景']
```

维护规则：

- 主角必须始终存在。
- 新元素出现时插入新行。
- 元素位置或状态变化时更新对应行。
- 只删除确实离开当前场景的元素，不要整体清空表。
- 地标必须包含 `所属区域` 和 `传说背景`，这样右侧详情才有信息可展示。

## 6. 详情弹窗逻辑

地图详情弹窗复用通用弹窗函数 `showDlg()`。

`dlgMe(i)` 会：

1. 从 `D.mapEls` 取元素；若 `D.mapEls` 为空，则从 `D.chars + D.sceneChars` 构造 fallback 元素。
2. 根据元素类型显示中文类型。
3. 追加地图元素字段：`所属区域`、`传说背景`。
4. 追加角色字段：`生命值`、`魔力值`、`体力值`、`当前装备`。
5. 尝试按姓名从 `D.chars + D.sceneChars` 找角色，补充 `信任度`、`立场`、装备等信息。
6. 调用 `showDlg()` 展示详情。

## 7. 地图生成状态与缓存

地图生成使用三个状态变量：

```js
var mapBusy=false;
var mapCache={};
var lastCity='';
```

含义：

- `mapBusy`：防止并发生成。生成中再次点击会提示“地图生成中，请稍候”。
- `mapCache`：按地点缓存 SVG，键是 `D.loc`。
- `lastCity`：记录上一次所在城市，用于判断是否刚到新城市。

刷新逻辑：

```js
async function doMap(force){
  if(mapBusy){toast('地图生成中，请稍候');return}
  if(force&&D.loc)delete mapCache[D.loc];
  if(!force&&mapCache[D.loc]){
    document.getElementById('mapBox').innerHTML=mapCache[D.loc];
    bindMC();
    toast('地图已刷新');
    return;
  }
  // 无缓存或强制重绘时进入生成流程
}
```

按钮语义：

- 刷新：`doMap(false)`，如果有缓存就直接复用。
- 重绘：`doMap(true)`，删除当前地点缓存后重新生成。

## 8. 地点粒度判断：城市大地图 vs 具体小场景

现有实现不是无脑生成同一种图，而是根据地点名称决定地图尺度。

城市名列表：

```js
var CITY_NAMES=[
  '圣城奥拉提姆',
  '银冠城',
  '铁门关',
  '红砂城',
  '卡拉迪姆',
  '碧水港',
  '星见塔',
  '阿卡迪亚',
  '翠幕永林',
  '铁炉深渊',
  '灰土地带'
];
```

`getMapScale(loc)` 规则：

1. 空地点返回 `scene`。
2. 包含 `·`、`-`、`—`、`/` 且长度大于 4，认为是具体子场景。
3. 匹配已知城市名且总长度不超过城市名长度 + 4，认为是城市级。
4. 长度小于等于 6 且无分隔符，倾向认为是城市级。
5. 其他情况返回 `scene`。

```js
function getMapScale(loc){
  if(!loc)return'scene';
  if(/[·\-—\/]/.test(loc)&&loc.length>4)return'scene';
  for(var i=0;i<CITY_NAMES.length;i++){
    if(loc.indexOf(CITY_NAMES[i])>=0&&loc.length<=CITY_NAMES[i].length+4)return'city';
  }
  if(loc.length<=6)return'city';
  return'scene';
}
```

`getCityFromLoc(loc)` 用于从子场景中提取城市名：

```js
function getCityFromLoc(loc){
  if(!loc)return'';
  for(var i=0;i<CITY_NAMES.length;i++){
    if(loc.indexOf(CITY_NAMES[i])>=0)return CITY_NAMES[i];
  }
  var parts=loc.split(/[·\-—\/]/);
  return parts[0]||loc;
}
```

生成提示词的尺度分支：

- 如果 `scale === 'city'` 且 `curCity !== lastCity`：绘制城市俯瞰全景大地图。
- 其他情况：绘制当前所在的具体小场景地图。

城市大地图提示：

```text
这是刚到达的城市，绘制城市俯瞰全景大地图。标注主要区域、街道、重要建筑位置。视角为鸟瞰俯视。
```

小场景提示：

```text
绘制当前所在的具体小场景地图（室内房间/街道/建筑内部/广场等局部区域）。视角为近距离俯视，只画当前房间或街道范围，不要画整座城市。标注房间内的家具、门窗、通道、桌椅等细节元素。
```

这个规则很关键。省掉它会导致 AI 经常在室内场景画成整座城市，或者刚进城却只画一个房间。那不是“风格差异”，是信息尺度错配。

## 9. AI 生成 Prompt 规范

生成函数 `doMap(force)` 会在检测到 `api.callAI` 可用时调用 AI 生成 SVG。

角色列表来自 `D.mapEls` 中类型为：

- `protagonist`
- `ally`
- `enemy`
- `npc`
- `主角`
- `友方`
- `敌方`
- `NPC`

元素列表来自 `D.mapEls` 中类型为：

- `landmark`
- `obstacle`
- `exit`
- `地标`
- `障碍物`
- `出口`

现有 Prompt 模板：

```text
你是中世纪奇幻地图绘制师。所有文字必须使用中文，严禁英文。
当前地点：{D.loc}
地图要求：{scaleHint}
场景中角色：{charList 或 暂无}
场景中元素：{landList 或 暂无}
SVG viewBox="0 0 800 600"背景#f5ead0。角色圆形标记圆内首字圆下全名。主角=#ff5f9e友方=#6bb7ff敌方=#e74c3c NPC=#f39c12。加class="cm" data-idx="序号"。只输出<svg>...</svg>
```

复现时必须保留的硬约束：

- 只输出 `<svg>...</svg>`，不要解释文本。
- SVG 尺寸必须是 `viewBox="0 0 800 600"`。
- 背景色使用 `#f5ead0`。
- 所有文字必须中文，严禁英文。
- 角色用圆形标记。
- 圆内显示名字首字，圆下显示全名。
- 角色颜色：
  - 主角：`#ff5f9e`
  - 友方：`#6bb7ff`
  - 敌方：`#e74c3c`
  - NPC：`#f39c12`
- 可点击元素必须带 `class="cm"` 和 `data-idx="序号"`。

`data-idx` 必须对应 `D.mapEls` 中的元素下标。否则 SVG 上点击元素时，`dlgMe(idx)` 会打开错误详情。

如果要让 AI 稳定生成可点击地图，不要只给它“角色名列表”和“元素名列表”。更可靠的输入应包含索引表，例如：

```text
地图元素索引：
0: 伊莲娜 / 主角 / 当前坐标(400,300)
1: 审判官 / NPC / 当前坐标(520,260)
2: 审判庭正门 / 出口 / 当前坐标(680,520)
```

并明确要求：

- `data-idx="0"` 只能用于索引 0 的元素。
- 禁止按名称重新排序。
- 禁止把地标、出口、NPC 的索引混用。
- 如果某个元素没有画进 SVG，不得把它的索引挪给其他元素。

当前本体 Prompt 只传入名称串，这是现有实现的简化写法；复现时如果追求点击详情稳定，最好补上“索引-名称-类型-坐标”的结构化列表。否则生成图看起来没问题，点起来却打开别人的详情——这种 bug 脏得很隐蔽。

## 10. 生成结果提取与降级

AI 返回后用正则提取 SVG：

```js
var result=await api.callAI([{role:'user',content:prompt}],{max_tokens:4000});
if(result){
  var m=String(result).match(/<svg[\s\S]*<\/svg>/i);
  if(m)svg=m[0];
}
```

如果 AI 失败，会走两级降级：

1. `D.mapEls.length > 0`：使用 `fbMap()` 根据地图元素表画 fallback SVG。
2. 没有地图元素：使用 `defMap()` 画默认当前位置地图。

生成完成后：

```js
mapCache[D.loc]=svg;
document.getElementById('mapBox').innerHTML=svg;
bindMC();
toast('地图已生成');
```

无论 AI 图还是 fallback 图，最终都注入 `#mapBox`，再调用 `bindMC()` 绑定点击事件。

缓存边界要注意：`mapCache` 的键只有 `D.loc`。如果地点不变，但 `D.mapEls` 的角色、坐标、地标发生变化，右侧列表会随 `loadAll()` 更新，已有 SVG 缓存却不会自动失效。此时普通“刷新”会继续复用旧 SVG，必须点“重绘”或在实现中加入更细的缓存失效策略。

可选的更稳策略：

- 缓存键从 `D.loc` 扩展为 `D.loc + 地图元素摘要`。
- 表格更新后，如果 `D.mapEls` 摘要变化，删除 `mapCache[D.loc]`。
- 摘要至少包含 `元素名称 / 元素类型 / X坐标 / Y坐标 / 状态`。

## 11. fallback 地图 fbMap()

`fbMap()` 是生产上很重要的兜底，不是摆设。AI 不可用或返回非法内容时，仍能用表格坐标生成可交互地图。

规则：

- SVG `viewBox="0 0 800 600"`。
- 背景 `#f5ead0`。
- 外框虚线 `#d4a853`。
- 顶部显示 `D.loc`。
- 遍历 `D.mapEls`。
- `X坐标`、`Y坐标` 转为整数；缺失时随机落在可视区域。
- 角色类元素画圆形标记：圆内首字，圆下全名。
- 非角色类元素用 `◆` 菱形符号显示。
- 每个元素包在 `<g class="cm" data-idx="idx">...</g>` 里。

角色判断：

```js
['protagonist','ally','enemy','npc','主角','友方','敌方','NPC'].indexOf(t)>=0
```

非角色会被当成地点/障碍/出口类元素显示。

注意：当前 fallback 的随机坐标使用 `Math.random()`，所以在缺少坐标时同一元素可能每次位置不同。要稳定复现，表格里应填写 `X坐标` 和 `Y坐标`。别指望随机数替你做稳定系统，太天真了。

## 12. 默认地图 defMap()

当没有 AI 结果，也没有 `D.mapEls` 时，`defMap()` 输出最小默认图：

- 羊皮纸背景。
- 顶部地点名。
- 中央主角/当前位置圆点。
- 显示“当前位置”。

这是空数据兜底，不能替代正式地图。正式地图应依赖 `sheet_MapElements` 提供元素。

## 13. 点击绑定 bindMC()

地图交互由 `bindMC()` 负责。

绑定优先级：

1. 绑定 `#mapBox .cm` 和 `#mapBox [data-idx]`。
2. 点击后读取 `this.dataset.idx`，调用 `dlgMe(idx)`。
3. 如果 AI 生成 SVG 没有 `cm` / `data-idx`，备用绑定所有 `circle[r]` 的父级 `g`。

核心逻辑：

```js
function bindMC(){
  document.querySelectorAll('#mapBox .cm, #mapBox [data-idx]').forEach(function(g){
    g.style.cursor='pointer';
    g.onclick=function(e){
      e.stopPropagation();
      var idx=parseInt(this.dataset.idx);
      if(!isNaN(idx))dlgMe(idx);
    };
  });

  var circles=document.querySelectorAll('#mapBox circle[r]');
  circles.forEach(function(c,i){
    var parent=c.closest('g');
    if(parent&&!parent.classList.contains('cm')&&!parent.dataset.idx){
      parent.dataset.idx=i;
      parent.style.cursor='pointer';
      parent.onclick=function(e){
        e.stopPropagation();
        dlgMe(i);
      };
    }
  });
}
```

备用绑定只能算补救。真正可靠的 SVG 必须由 AI 按 Prompt 输出 `class="cm" data-idx="序号"`。

## 14. 缩放与拖拽

地图支持鼠标滚轮缩放、鼠标拖拽、双指触控缩放和触控拖拽。

状态变量：

```js
var mapZoom=1;
var mapPan={x:0,y:0};
var mapDrag=false;
var mapStart={x:0,y:0};
```

缩放范围：`0.5` 到 `3`。

应用变换：

```js
function applyMapTransform(){
  var svg=document.querySelector('#mapBox svg');
  if(svg)svg.style.transform='scale('+mapZoom+') translate('+mapPan.x/mapZoom+'px,'+mapPan.y/mapZoom+'px)';
}
```

复位：

```js
function resetMapView(){
  mapZoom=1;
  mapPan={x:0,y:0};
  applyMapTransform();
}
```

拖拽时如果事件目标在 `.cm` 内，则不开始拖拽，避免点击地图元素时被拖拽逻辑吞掉：

```js
if(e.target.closest('.cm'))return;
```

## 15. 自动刷新机制

初始化时：

```js
document.addEventListener('DOMContentLoaded',function(){
  loadAll();
  initMapZoom();
  var api=getApi();
  if(api){
    if(typeof api.registerTableUpdateCallback==='function'){
      try{api.registerTableUpdateCallback(function(){loadAll()})}catch(e){}
    }
    if(typeof api.registerTableFillEndCallback==='function'){
      try{api.registerTableFillEndCallback(function(){loadAll()})}catch(e){}
    }
    if(typeof api.registerTableFillStartCallback==='function'){
      try{api.registerTableFillStartCallback(function(){document.getElementById('dbChip').textContent='⟳ 更新中'})}catch(e){}
    }
  }
  window.addEventListener('message',function(ev){
    if(ev.data==='tableUpdated')loadAll();
  });
});
```

也就是说地图会在以下情况刷新数据：

- DOM 加载完成。
- 数据库表格更新回调。
- 数据库填表结束回调。
- 收到 `postMessage` 的 `tableUpdated` 通知。

## 16. 复现最小清单

其他 AI 要生成同款场景地图，至少要实现以下内容：

1. DOM：地图页、按钮、`#mapBox`、`#mapList`、`#mapLocName`、`#mapLoading`。
2. CSS：双栏布局、380px 高地图框、右侧列表、按钮、`.cm` hover、元素列表样式。
3. 数据：读取 `D.loc`、`D.mapEls`、`D.chars`、`D.sceneChars`。
4. 表结构：实现 `sheet_MapElements`，字段必须包含 `元素名称 / 元素类型 / X坐标 / Y坐标 / 描述 / 所属区域 / 传说背景`。
5. 渲染列表：`renderMapList()`，按地点与角色分组。
6. 详情弹窗：`dlgMe()`，用地图元素字段并补充角色表字段。
7. 生成逻辑：`doMap(force)`，包含并发锁、缓存、AI 调用、SVG 提取、fallback、默认图。
8. 地点尺度：`CITY_NAMES`、`getMapScale()`、`getCityFromLoc()`，用于区分城市大地图和局部小场景。
9. Prompt：中文、中世纪奇幻、`viewBox="0 0 800 600"`、背景 `#f5ead0`、角色颜色、`class="cm" data-idx="序号"`。
10. 交互绑定：`bindMC()`。
11. 缩放拖拽：`initMapZoom()`、`applyMapTransform()`、`resetMapView()`。
12. 初始化：DOMReady 后 `loadAll()`、`initMapZoom()`，并注册数据库表格更新回调。

## 17. AI 生成 SVG 的推荐输出格式

让 AI 绘制时，推荐强制输出类似结构：

```html
<svg viewBox="0 0 800 600" xmlns="http://www.w3.org/2000/svg">
  <rect width="800" height="600" fill="#f5ead0"/>
  <text x="400" y="35" text-anchor="middle" fill="#5c4033" font-size="16" font-weight="bold">圣城奥拉提姆·审判庭</text>

  <!-- 地形、墙体、家具、道路、门窗等 -->

  <g class="cm" data-idx="0">
    <circle cx="400" cy="300" r="20" fill="#ff5f9e" stroke="#fff" stroke-width="2.5"/>
    <text x="400" y="305" text-anchor="middle" fill="#fff" font-size="12" font-weight="bold">伊</text>
    <text x="400" y="332" text-anchor="middle" fill="#ff5f9e" font-size="10">伊莲娜</text>
  </g>

  <g class="cm" data-idx="1">
    <circle cx="520" cy="260" r="20" fill="#f39c12" stroke="#fff" stroke-width="2.5"/>
    <text x="520" y="265" text-anchor="middle" fill="#fff" font-size="12" font-weight="bold">审</text>
    <text x="520" y="292" text-anchor="middle" fill="#f39c12" font-size="10">审判官</text>

```

`data-idx="0"` 必须指向 `D.mapEls[0]`，`data-idx="1"` 必须指向 `D.mapEls[1]`。如果顺序乱了，点击详情就会错位。

## 18. 和旧版通用场景地图文档的区别

项目里还有通用文档：`奶龙王一键制卡/docs/场景地图系统/README.md`。那份文档总结的是另一个项目的通用场景地图模块，使用 `SceneMapState`、`#sceneMapContent`、`.character-marker`、`refreshSceneMap()` 等命名。

王国卡当前实现不同：

| 项目 | 通用文档版本 | 王国卡状态栏版本 |
|---|---|---|
| 状态对象 | `SceneMapState` | `mapBusy / mapCache / lastCity` + 全局 `D` |
| 地图容器 | `#sceneMapContent` | `#mapBox` |
| 标记类名 | `.character-marker` | `.cm` |
| 点击定位 | `data-name / data-type` | `data-idx` 对应 `D.mapEls` 下标 |
| 数据源 | 角色列表为主 | `sheet_MapElements` 为主，角色表为 fallback |
| 地图尺度 | 单一场景 | 城市大地图 / 局部小场景自动判断 |
| 交互 | 点击角色详情 | 点击任意地图元素详情 + 右侧列表 + 缩放拖拽 |

因此，如果目标是复现“王国卡内状态栏”的地图，应以本文件为准，不要照搬通用文档里的 `SceneMapState` 版本。照搬会跑偏，尤其是点击协议和数据源完全不同。

## 19. 已知边界与注意事项

- AI 生成 SVG 没有做严格净化，只是正则提取 `<svg>...</svg>` 后注入 `innerHTML`。在当前角色卡环境里这是既有做法，但如果迁移到普通 Web 页面、公开站点或更严格的运行环境，必须增加 SVG 白名单净化，至少过滤 `<script>`、事件属性（如 `onclick`）、外链资源、`foreignObject` 等高风险内容。
- fallback 缺少坐标时会随机放置元素；要稳定复现，必须填表坐标。
- `lastCity` 只在运行时内存中记录，刷新页面后会重置。
- `mapCache` 也是内存缓存，页面刷新后丢失；同一地点下地图元素变化时也不会自动失效，除非用户点“重绘”或实现额外缓存摘要。
- `data-idx` 与 `D.mapEls` 顺序强绑定，生成 SVG 时不能重排元素索引。
- 如果 `D.mapEls` 为空，地图仍可用角色表 fallback，但缺少地标、出口、障碍物等空间信息，地图质量会明显下降。
- 地图 CSS 依赖状态栏全局主题变量：`--line`、`--card`、`--card2`、`--rose`、`--hot`、`--muted`、`--dim`、`--text`。如果迁移到独立页面，要补齐这些变量；否则功能能跑，视觉会塌成一团。

## 20. 一句话复现标准

王国卡场景地图 = `sheet_MapElements` 驱动的 800×600 羊皮纸 SVG 地图，按地点粒度选择城市/小场景 Prompt，通过 `AutoCardUpdaterAPI.callAI` 生成，失败时用表格坐标 fallback，所有可点击元素用 `.cm[data-idx]` 绑定到 `dlgMe()`，并配套右侧列表、详情弹窗、缓存、刷新/重绘、缩放拖拽。
