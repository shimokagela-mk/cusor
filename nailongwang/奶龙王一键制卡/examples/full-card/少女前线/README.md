# 少女前线

## 当前版本

v0.1 首包验收中

## 内容范围

- 世界观：少女前线原作世界观、阵营、技术体系、战役脉络。
- 人物：战术人形、关键 NPC、阵营与敌方索引世界书条目。
- 表格：`tables/table-template.json` 与 `tables/readable/` 维护 ACU/shujuku 表格模板。
- 前端：开场初始化、战斗界面正则，以及作为酒馆助手脚本运行的常驻待机控制台。
- 资源：`assets/` 中包含待机背景与 K11 立绘资源。

## 构建入口

```bash
node tools/build-card.js projects/少女前线/current-plan.yaml
```

构建输入：`current-plan.yaml`；人类可读制作计划保留在 `current-plan.md`。输出目录：`projects/少女前线/release/`。

## 已知限制

- 当前项目为首次构建/打包场景，不是 `unpacked/` 目录回包场景。
- 全仓 `npm run validate` 仍可能受其他项目结构与 `.DS_Store` 残留影响；判断少女前线首包时需区分本项目问题与全仓历史问题。
