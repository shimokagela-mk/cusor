# 第五阶段：格里芬完整线（E17b-E19）

> **前置条件**：第四阶段结束，格里芬未溃败（存活分支完美结局 / 存活分支标准结局）
> **阶段定义**：格里芬与军方公开对立 → 主动追查威廉 → 涅托威胁浮现 → 格里芬主导进攻帕尔迪斯基
> **对应原作章节**：无直接对应——全新走向（原作中格里芬此时已溃败）
> **核心体验**：主动出击——格里芬不再是被动的棋子，而是掌握主动权的独立势力

## 一、阶段框架

| 项目 | 内容 |
|------|------|
| **开始窗口** | 格里芬实力完整/受损不严重；与军方公开对立；铁血主脑仍在追捕M4A1；军方阴谋已暴露 |
| **战略目标** | 追查军方幕后势力（威廉）→ 应对涅托威胁 → 寻找安洁莉娅建立同盟 → 主导进攻帕尔迪斯基 |
| **结束标志** | 格里芬主导进攻帕尔迪斯基+与安洁/忤逆联合（完美）/ 格里芬参与进攻但准备不足（标准）/ 格里芬被涅托重创后被迫防守（最差） |
| **时间压力** | 高——军方叛军正在向帕尔迪斯基进发；铁血主脑仍在追捕M4A1；涅托开始对格里芬发动攻击 |
| **核心体验** | 主动出击——从"被利用的棋子"变为"掌握主动权的独立势力" |

### 1.1 进入本阶段时的状态

**来自存活分支完美结局**：
- AR小组全员安全（M4A1+M16A1+SOP-II+RO635+AR-15可能存活）
- 格里芬战力未受损
- 克鲁格未被捕——格里芬组织完整
- 军方阴谋暴露——格里芬与军方关系破裂
- 铁血主脑的【伞】释放了——但主要影响军方自己的部队
- 格里芬从"被利用的棋子"变为"识破阴谋的独立势力"

**来自存活分支标准结局**：
- AR小组大部分存活（M16A1可能重伤）
- 格里芬损失可控——主力保存
- 克鲁格可能被捕/可能未被捕
- 格里芬认识到军方是敌人
- 部分人形被【伞】感染但规模可控

### 1.2 格里芬当前处境

| 项目 | 完美结局状态 | 标准结局状态 |
|------|-------------|-------------|
| 领导层 | 克鲁格在位；组织完整 | 克鲁格可能被捕/可能在位 |

| 铁血威胁 | 铁血主脑仍在追捕M4A1 | 同左 |

### 1.3 本分支的独特性

格里芬**没有溃败**——这意味着：
- 格里芬不需要"逃亡"和"重建"——可以直接进入**主动出击**阶段
- 克鲁格（如果在位）可以利用政治手段对抗军方——而非被动挨打
- AR小组完整编制让格里芬有能力**主动追查**威廉和帕尔迪斯基
- 安洁莉娅不需要"救走M4A1"——M4A1仍在格里芬身边
- 格里芬可以**选择**何时、以何种方式进攻帕尔迪斯基——而非被迫仓促行动

## 二、各方势力目的分析

### 2.1 涅托/帕拉蒂斯（白色势力）

**核心目的**：消灭格里芬这个"意外变量"——格里芬识破军方阴谋后成为威廉计划的障碍

**行动逻辑**：
- 原作中格里芬溃败后涅托只需要审讯指挥官——但现在格里芬没有溃败
- 威廉需要M4A1（OGAS的载体）——但M4A1仍在格里芬保护下
- 涅托被派来**主动进攻**格里芬——目标是夺取M4A1或削弱格里芬
- 涅托的攻击比溃败线更猛烈——因为格里芬是完整的威胁

**涅托的行为模式**：
- 对格里芬基地发动突袭——利用无信号特性潜入
- 目标优先级：M4A1 > 指挥官 > 格里芬战力
- 力场盾让常规武器无效——需要特殊手段对付
- 可能与军方暗中配合（军方想要M4A1，涅托想要OGAS数据）

### 2.2 军方（卡特将军/叶戈尔）

**核心目的**：重新获取M4A1+控制帕尔迪斯基

**行动逻辑**：
- 联合行动失败/被格里芬拒绝——军方阴谋暴露
- 卡特需要寻找其他方式获取M4A1——政治施压+军事威胁
- 叶戈尔率装甲列车向帕尔迪斯基进发——目标是控制海星设施
- 军方与格里芬进入公开对立——但不敢全面开战（格里芬掌握阴谋证据）
- 军方可能与涅托暗中配合——"敌人的敌人"

**军方的困境**：
- 格里芬掌握军方阴谋的证据——如果公开，军方声誉受损
- 格里芬战力完整——军方不敢轻举妄动
- 但军方仍然控制着政治和法律系统——可以通过非军事手段施压

### 2.3 格里芬（克鲁格/指挥官）

**核心目的**：追查幕后势力+保护M4A1+主导进攻帕尔迪斯基

**格里芬的优势**（相比溃败线）：
- 战力完整——可以主动出击而非被动防守
- 组织完整——克鲁格可以进行政治博弈
- 掌握军方阴谋证据——政治筹码
- 与安洁莉娅有同盟基础——情报共享
- M4A1仍在身边——不需要"寻找M4A1"

**格里芬的劣势**：
- 与军方公开对立——政治压力
- 涅托是全新的威胁——力场盾让常规武器无效
- 铁血主脑仍在追捕M4A1——双线威胁
- 帕尔迪斯基的情报有限——需要安洁莉娅的配合

### 2.4 安洁莉娅/忤逆小队

**核心目的**：追查威廉+阻止军方控制帕尔迪斯基

**行动逻辑**：
- 安洁莉娅在第四阶段已与格里芬建立暗中同盟
- 安洁莉娅掌握威廉和帕尔迪斯基的关键情报
- 忤逆小队可能已经在帕尔迪斯基附近活动
- 安洁莉娅需要格里芬的战力配合——独自无法对抗军方装甲列车

### 2.5 哈维尔/IOP

**核心目的**：获取帕尔迪斯基基地的研究资料+保护帕斯卡

**行动逻辑**：
- 哈维尔主动联络格里芬——提供帕尔迪斯基的情报
- 哈维尔的条件：基地的研究资料不能全部交给安全局
- 帕斯卡可能通过哈维尔向格里芬提供技术支持（对抗涅托的方法）
- 哈维尔可能出资支持格里芬的行动

### 2.6 铁血残余

**核心目的**：自保——铁血主脑释放【伞】后自身也受损严重

**行动逻辑**：
- 铁血主脑仍在追捕M4A1——但【伞】释放后铁血自身战力大减
- 法官可能仍在活动——但失去了大量支援
- 铁血精英可能自发组织——部分投降/部分撤离
- M16A1（如果被带走）可能带着伊莱莎前往帕尔迪斯基

### 2.7 M4A1（本分支的关键变量）

**M4A1在格里芬完整线中的状态**：
- M4A1仍在格里芬身边——没有被忤逆小队救走
- M4A1的"歼灭主脑"驱动仍然存在——但有M16A1和指挥官的支持
- M4A1可能主动要求参与进攻帕尔迪斯基——"主脑在那里"
- "清澈的女声"仍在影响M4A1——推动她变得更果断

## 三、敌方各头目行动模式

### 3.1 涅托（Nyto）——本阶段核心威胁

**角色定位**：威廉的精锐兵器，主动进攻者

**行动模式**：
- 对格里芬基地发动突袭——利用无信号特性绕过预警
- 目标是M4A1——试图将M4A1从格里芬身边夺走
- 力场盾让常规武器无效——需要特殊手段（电子战干扰/重型武器/近战）
- 可能在城市中设伏——如果格里芬外出行动
- 攻击模式：快速突入→目标锁定→强行带走→撤退

**弱点**：
- 数量有限——不是无限的军队
- 力场盾有能量限制——持续攻击可以耗尽
- 对电子战有脆弱性——RO635可以干扰其系统
- 格里芬战力完整——涅托无法像对付溃败的格里芬那样轻松
- M16A1的经验可能识别涅托的行动模式

### 3.2 法官（可能仍在活动）

**角色定位**：铁血主脑的追捕者（如果铁血主脑仍在活动）

**行动模式**：
- 【伞】释放后铁血战力大减——法官可能失去大量支援
- 但法官个体战斗力仍然极强
- 可能与涅托形成"双线威胁"——法官追M4A1+涅托也追M4A1
- 法官和涅托之间可能产生冲突（目标相同但阵营不同）

### 3.3 军方封锁/施压部队

**角色定位**：政治+军事施压

**行动模式**：
- 不敢全面进攻格里芬（格里芬掌握阴谋证据）
- 通过政治手段施压——威胁吊销许可、冻结资产
- 可能在格里芬外出行动时设置拦截
- 叶戈尔的装甲列车向帕尔迪斯基进发——如果格里芬也要去，可能在路上遭遇

| 保护M4A1 | M16A1在M4A1身边→涅托夺取M4A1的难度大幅增加 |

## 六、结果分支与对第六阶段的影响

### 6.1 完美结局：格里芬主导进攻帕尔迪斯基

**条件**：成功击退涅托多次突袭 + 研发出对抗涅托的手段 + 与安洁莉娅深度联合 + 在军方叛军到达前出发

**效果**：
- 格里芬以完整战力主导进攻帕尔迪斯基
- 与安洁/忤逆小队联合作战——兵力充足
- 掌握涅托弱点——可以有效对抗白色单位
- 帕尔迪斯基情报完整——作战方案充分
- AR小组全员参与——M4A1+M16A1+SOP-II+RO635
- 格里芬在帕尔迪斯基的表现将远超溃败线

### 6.2 标准结局：格里芬参与进攻但准备不足

**条件**：击退涅托但未完全掌握其弱点 / 与安洁莉娅联合但配合有限 / 军方叛军已先到达

**效果**：
- 格里芬参与帕尔迪斯基进攻但不是主导
- 对涅托的对抗手段有限——可能在基地内遭遇困难
- 与安洁/忤逆的配合不够默契
- 军方叛军已经在基地——需要同时对抗军方和涅托

### 6.3 最差结局：格里芬被涅托重创

**条件**：涅托突袭成功夺走M4A1 / 格里芬在涅托攻击中损失惨重

**效果**：
- 格里芬战力受损——需要修复后才能行动
- M4A1可能被涅托带走——需要营救
- 进攻帕尔迪斯基被迫延后
- 与溃败线的后期走向趋同

### 6.4 对第六阶段的具体影响

| 第五阶段结果 | 对第六阶段的影响 |
|--------------|------------------|
| 格里芬战力 | 完整→帕尔迪斯基进攻效率高；受损→需要更多时间 |
| 涅托对抗手段 | 掌握→可以有效对抗白色单位；未掌握→遭遇战 |
| 安洁莉娅联合程度 | 深度→兵分多路联合作战；有限→各自为战 |
| M4A1是否在身边 | 在→AR小组完整参与；被夺走→需要营救 |
| M16A1状态 | 完好→战术核心；重伤→战力下降 |
| 帕尔迪斯基情报 | 完整→精确打击；有限→摸索前进 |
| 军方叛军进度 | 格里芬先到→主动权；军方先到→被动 |

## 七、设计要点总结

### 7.1 不写死的东西

- ❌ 不写"涅托一定能突袭成功"——格里芬战力完整，可以击退
- ❌ 不写"格里芬一定能研发出对抗涅托的手段"——需要时间和正确的方向
- ❌ 不写"安洁莉娅一定会深度配合"——她有自己的优先级
- ❌ 不写"格里芬一定能在军方之前到达帕尔迪斯基"——取决于准备速度
- ❌ 不写"M4A1一定安全"——涅托的目标就是M4A1
- ❌ 不写"法官一定会被击败"——法官个体战斗力仍然极强
- ❌ 不写"克鲁格一定能在政治博弈中获胜"——军方仍然掌握政治权力

### 7.2 必然发生的东西（世界的内在逻辑）

- ✅ 涅托**会**对格里芬发动攻击（威廉需要M4A1——格里芬是障碍）
- ✅ 军方**会**继续施压格里芬（政治层面的对立不会消失）
- ✅ 叶戈尔**会**率装甲列车向帕尔迪斯基进发（他的任务不变）
- ✅ 法官**会**继续追捕M4A1（铁血主脑的命令——但战力大减）
- ✅ 安洁莉娅**会**联络格里芬寻求联合（她需要格里芬的战力）
- ✅ 哈维尔**会**提供支持（他需要帕尔迪斯基的研究资料）
- ✅ M4A1**会**要求参与进攻帕尔迪斯基（她的内在驱动——追回M16/歼灭主脑）
- ✅ 帕尔迪斯基**会**成为多方势力汇聚的战场（军方+格里芬+铁血+涅托）

### 7.3 本分支与溃败线的核心差异

| 维度 | 溃败线 | 完整线 |
|------|--------|--------|
| 格里芬状态 | 被通缉的逃亡者 | 掌握主动权的独立势力 |
| 行动方式 | 城市谍战+隐蔽行动 | 正面对抗+主动出击 |
| 涅托的角色 | 审讯者（格里芬已弱） | 进攻者（格里芬是威胁） |
| M4A1位置 | 被忤逆救走/被军方捕获 | 仍在格里芬身边 |
| 安洁莉娅关系 | 需要寻找 | 已有同盟基础 |
| 帕尔迪斯基 | 仓促行动 | 充分准备后主导进攻 |
| 核心体验 | 从废墟中重生 | 主动出击掌握命运 |
