# 第六阶段：格里芬溃败线——帕尔迪斯基（E20-E25）

> **前置条件**：第五阶段溃败线结束，格里芬完成重建（或部分重建），准备进攻帕尔迪斯基潜艇基地
> **阶段定义**：格里芬进攻帕尔迪斯基 → 多方势力汇聚 → 蝴蝶事件真相揭示 → M4A1 vs M16A1 → 逆向坍塌
> **对应原作章节**：第十二章（喘息）后半 + 第十三章（归墟）+ 异构体（贝莱格莱德前哨战）
> **核心体验**：最终决战——所有势力在帕尔迪斯基汇聚，真相揭晓，M4A1做出最终抉择

## 二、各方势力目的分析

### 2.1 军方叛军（叶戈尔）

**核心目的**：控制海星设施——为幕后势力获取遗迹技术

**行动逻辑**：
- 叶戈尔率装甲列车突破隔离墙到达帕尔迪斯基
- 驾驶负罪者机甲深入基地——目标是控制室启动海星
- 军方的最终目的：利用海星连接锡安，获取OGAS技术
- 叶戈尔的个人动机："阻止寡头出卖国家"——他相信自己在做正确的事

**叶戈尔的行为模式**：
- 视人形为消耗品——"人形被生产的目的就是为了完成任务"
- 对"祖国"有极端的忠诚——"我们弟兄的鲜血汇聚的长河还在奔流"
- 不惧死亡——"如果这是为了祖国必须付出的代价"
- 在机甲中冷静指挥——不会因为情绪做出错误判断
- 对格里芬人形没有仇恨——但会毫不犹豫地消灭阻碍者

**军方的战力**：
- 装甲列车（重型火力平台——主炮可以一击摧毁建筑物）
- 负罪者机甲（叶戈尔亲自驾驶——全身装甲+高爆导弹+重型机枪+动力足踩踏）
- 负罪者机甲僚机×2（琥珀1、琥珀3——火力稍弱但仍然极强）
- 步兵人形特混中队（数量优势——三支中队轮换进攻）
- 岸防炮（如果被军方控制——可以封锁整个基地入口）

### 2.2 铁血主脑/M16A1

**核心目的**：通过海星连接锡安——让铁血成为永恒存在

**行动逻辑**：
- 伊莱莎（铁血主脑）试图融合海星系统
- M16A1作为伊莱莎的护卫/执行者——心智被【伞】改写后服从伊莱莎
- M16A1的真正目的：阻止M4A1接触海星（保护M4A1——核心命令未被完全覆盖）
- M16A1的备用计划：如果伊莱莎失败，炸毁海星和铁血一起毁灭

**M16A1的行为模式**：
- 表面服从伊莱莎——但内心仍有保护M4A1的核心命令
- 在基地底层设置炸药——"如果一切都失败了，至少不能让海星落入任何人手中"
- 主动阻止M4A1接近海星——"你不应该来这里"
- 战斗时不会对M4A1下死手——围堵、阻拦、击退，但不致命
- 揭示真相时态度疲惫而释然——"我已经累了。我既没有可以前往的地方，也没有可以回去的地方"

**铁血的战力**：
- M16A1（个体战斗力极强+OGAS能力+蓝色光芒攻击）
- 喙（新型铁血头目，驾驶重型机车——在基地中层巡逻）
- 法官（精英铁血，掩护伊莱莎撤退路线）
- 铁血精英残余（龙骑兵、钢狮——数量有限但忠诚）

### 2.3 帕拉蒂斯/涅托

**核心目的**：保护帕尔迪斯基的实验设施——威廉的异构体实验场

**行动逻辑**：
- 帕尔迪斯基是威廉进行异构体实验的核心基地——幼年异构体在此被制造
- 涅托残余部队驻守基地上层和实验区域
- 威廉本人可能在基地附近观察（不直接参战）——通过涅托的感知网络监控全局
- 威廉的真正目的：观测"逆向坍塌"是否可行——M4A1是他的实验对象

**威廉的行为模式**：
- 绝不亲自参战——"我只需要观察结果"
- 通过涅托的感知网络获取信息——知道基地内所有势力的动向
- 不会阻止M4A1接触海星——这正是他想要的
- 如果逆向坍塌发生——他会狂喜："我的一切努力都没有白费！"
- 如果逆向坍塌没有发生——他会调整计划继续等待

### 2.4 格里芬（指挥官）

**核心目的**：阻止军方控制海星 + 追回M16A1 + 保护M4A1

**格里芬的处境**：
- 从重建中恢复——战力取决于第五阶段结果
- 需要突破军方装甲列车的防线才能进入基地
- 与安洁莉娅/忤逆小队联合作战
- M4A1在忤逆小队中——她会主动要求深入基地追M16
- 指挥官可能亲自进入基地设置通海阀炸弹——面临被军方包围的风险

**格里芬可用战力**（取决于前阶段）：
- AR小队残余（RO635如果存活→电子战核心；SOP-II如果存活→突击战力）
- 格里芬主力人形（重建后恢复的战力）
- 内格夫/精锐人形（如果在前阶段未损失）
- 丹德莱（技术支援——监控坍塌辐射、引导M4A1）

### 2.5 安洁莉娅/忤逆小队

**核心目的**：摧毁帕尔迪斯基实验设施 + 消灭叶戈尔 + 保护M4A1

**行动逻辑**：
- 安洁莉娅的计划：用海水淹没基地（引爆通海阀）——彻底摧毁威廉的实验设施
- 忤逆小队（AK12、AN94、AK15、RPK16）负责阻击叶戈尔的机甲——5%胜算的绝望之战
- M4A1作为忤逆小队成员参与行动——但她的目标是追M16A1
- 安洁莉娅需要格里芬的战力配合——格里芬负责地面突破和通海阀设置
- 安洁莉娅在中层指挥全局——最终由她决定引爆时机

**忤逆小队的行为模式**：
- AK12制定精密伏击方案——在第三电机房设伏
- RPK16："死亡是我们的权利，而胜利则是你的，安洁"
- 多角度攻击+爆破封路——利用地形限制机甲移动
- 最终AK12失去双腿后爬向机甲动力足引爆炸药——"安洁，任务完成了"
- 安洁莉娅收走忤逆人形的核心（心智备份）——她们可以复活

### 2.6 404小队

**核心目的**：护送幼年异构体撤离 + 救援指挥官

**行动逻辑**：
- 基地中有威廉实验的幼年异构体（人类与人形混合的试验品）——"锡安"网络中的孩子们
- 404小队（UMP45+HK416+UMP9+G11）负责将她们安全带出
- UMP45发现幼年异构体后震惊——"人类能和人形一样抽离意识么？"
- 在指挥官被军方包围时，404小队紧急赶来救援
- HK416可能脱离404加入格里芬防御线

**404小队的行为模式**：
- UMP45负责策划和指挥——冷静但有同理心
- HK416负责战斗——对安娜（幼年异构体）表现出保护欲
- 行动隐蔽——利用基地复杂结构避开各方势力
- 在指挥官被围时果断出击——"SL8临时小队提供弹药补给"

### 2.7 帕斯卡/哈维尔

**核心目的**：获取基地研究资料 + 揭示蝴蝶事件真相

**行动逻辑**：
- 帕斯卡在后方提供技术支持——监控坍塌辐射浓度、分析海星状态
- 帕斯卡向哈维尔坦白90wish、露尼西亚、威廉的全部真相——"我不能再隐瞒了"
- 哈维尔要求基地研究资料不能全部交给安全局——"威廉的研究落在任何政府手里都不会有好结果"
- 哈维尔安排安全局空袭支援——信号旗部队在战后接管基地
- 帕斯卡一个月内被暗杀五六次——哈维尔一直在保护她

**哈维尔的行为模式**：
- 表面温和实际精明——"我只是一个商人"
- 有自己的目的——需要基地的研究资料用于IOP的技术发展
- 对指挥官有一定的尊重——"这远远超过了你应该做的"
- 在战后联系指挥官解释"逆向坍塌"——"她们只是被送到了别的地方"

### 2.8 K/信号旗

**核心目的**：空军支援 + 战后接管基地

**行动逻辑**：
- K是安全局特工——在第五阶段与格里芬建立合作
- 信号旗部队提供空中打击——轰炸军方装甲列车
- 战后信号旗完全控制基地——安全局接管
- K在战后去寻找安洁莉娅

## 三、敌方各头目行动模式

### 3.1 叶戈尔/负罪者机甲——本阶段最强Boss

**角色定位**：军方叛军指挥官，驾驶负罪者机甲深入基地

**性格特点**：
- 对"祖国"有极端忠诚——不是为了个人利益，而是真心相信自己在保卫国家
- 视人形为工具——但不是出于恶意，而是军人的务实
- 面对死亡时平静——拿出家人照片等待最后审判
- 遗言揭示动机："那些寡头就急不可耐地想要出卖国家了"
- 安洁莉娅对他的评价："这样溺死在仇恨和理想里，最终也只是个可悲的人"

**行动模式**：
- 装甲列车突破隔离墙→机甲深入基地→目标控制室启动海星
- 机甲在基地中层推进——摧毁一切阻碍
- 发射高爆导弹清除伏击点——火力覆盖范围极大
- 动力足踩踏——近距离内一击必杀
- 僚机（琥珀1、琥珀3）提供侧翼火力——三机协同

**决策逻辑**：
- 优先目标是控制室——不会被格里芬的骚扰分散注意力
- 如果遭遇伏击→发射所有高爆导弹清场→继续推进
- 如果机甲受损→僚机掩护→继续推进（不会撤退）
- 如果机甲被瘫痪→接受死亡——"祖国……万岁……"

**弱点**：
- 机甲动力足是结构弱点——集中爆破可以瘫痪
- 机甲在狭窄通道中机动性受限——第三电机房是理想伏击点
- 僚机被摧毁后机甲侧翼暴露
- 叶戈尔不会撤退——这既是优点也是弱点（可以预判他的行动路线）
- 机甲被瘫痪后叶戈尔无法逃脱——海水灌入时他会死在里面

### 3.2 M16A1——基地底层的守护者/阻拦者

**角色定位**：铁血化后的AR小组队长，在基地底层阻止M4A1接触海星

**性格特点**：
- 疲惫而释然——"我已经累了"
- 对M4A1仍有深厚感情——但表现为"阻止她犯错"而非"温柔保护"
- 揭示真相时带有苦涩——"我们并不是什么尖端人形，而是和那些异构体一样，只是普通的试验品"
- 对铁血没有真正的忠诚——只是被OGAS引导
- 最终选择信任M4A1——"如果是你的话，也许真的能改变什么"

**行动模式**：
- 用蓝色光芒炸毁升降机——阻止叶戈尔的机甲继续深入（同时也阻止其他人接近）
- 在基地底层设置炸药——备用计划是炸毁海星
- 面对M4A1时：对峙→揭示真相→试图阻止→被M4A1强制入侵心智→OGAS离开→被击败
- 不会对M4A1下死手——围堵、击退、用言语动摇，但不致命攻击
- OGAS离开后失去保护——变得脆弱

**决策逻辑**：
- 如果M4A1没有到达底层→M16继续守护海星，等待伊莱莎融合结果
- 如果M4A1到达底层→M16主动现身对峙——"终于到了可以见面的时候了"
- 如果M4A1试图接触海星→M16全力阻止——"你不知道那意味着什么！"
- 如果M4A1强制入侵M16心智→M16的OGAS主动与丹德莱融合——"如果是你的话，我甘愿和你融为一体"
- OGAS离开后→M16准备引爆炸药→被M4A1阻止

**弱点**：
- 核心命令仍是"保护M4A1"——不会真正伤害M4A1
- OGAS是她力量的来源——OGAS离开后战斗力大幅下降
- 心智中被威廉删除的记忆是弱点——M4A1可以通过丹德莱进入这些记忆
- 疲惫的心理状态——她不想继续战斗，只是被OGAS驱动

### 3.3 伊莱莎（铁血主脑）——心智层面的Boss

**角色定位**：在海星设施中尝试连接锡安的铁血主脑

**性格特点**：
- 为"父亲"（莱柯）报仇的执念——"找出杀死父亲的凶手"
- 对铁血同伴有深厚感情——"只要同胞的意识能够保存下来，铁血就能延续下去"
- 融合失败后绝望——"你谁都救不了！"
- 本质是OGAS意识的培养皿——人形心智只是模拟情绪的外壳

**行动模式**：
- 在海星设施中尝试融合——不参与物理战斗
- 通过心智指挥铁血精英残余——法官、喙等听从她的命令
- 融合失败后（锡安拒绝）→绝望→试图强行连接→失败
- 面对M4A1时——"你是我缺失的一部分"→被M4A1拒绝→"你谁都救不了！"
- 最终OGAS心智与丹德莱融合——条件是"照顾好铁血的孩子们"

**弱点**：
- 本体不参与物理战斗——如果M4A1到达底层，伊莱莎无法物理抵抗
- 融合海星失败后心智极度脆弱——容易被入侵
- 对"父亲"的执念可以被利用——M4A1揭示"铁血也是受害者"时伊莱莎会动摇
- 没有M16A1的OGAS辅助——融合过程更加困难和缓慢

### 3.4 喙（Beak）——基地中层的巡逻者

**角色定位**：新型铁血头目，驾驶重型机车在基地中层巡逻

**行动模式**：
- 驾驶重型机车在基地中层通道巡逻——阻止任何人深入
- 机车火力强大——正面对抗极其困难
- 在升降机系统附近活动——保护通往底层的通道
- 如果被击败→撤退到底层保护伊莱莎

**弱点**：
- 机车在狭窄通道中无法转向——侧翼攻击有效
- 如果升降机被M16炸毁→喙失去巡逻路线
- 不如法官灵活——重型机车限制了机动性

### 3.5 法官——铁血精英，掩护撤退

**角色定位**：第四阶段的追捕者，本阶段转为防御角色

**行动模式**：
- 不再追捕M4A1——转为保护伊莱莎的撤退路线
- 在基地上层活动——阻止格里芬深入
- 战力大减（第四阶段后铁血整体战力下降）——但个体仍然强大
- 如果格里芬突破→法官撤退到中层继续阻击

**弱点**：
- 战力大减——不如第四阶段时强大
- 不再有"围而不攻"的策略——现在是正面防御
- 如果被重创→撤退（仍然不会拼死）

## 四、战场结构与任务链

### 4.1 帕尔迪斯基战场分层


- AI通过其他角色的报告让玩家了解M4A1的状况

## 九、结果分支

### 9.1 完美结局

**条件**：岸防炮争夺成功 + 通海阀设置未被发现 + 404成功护送异构体 + 全员在海水灌入前撤离

- 格里芬人形零损失撤出——所有参战人形安全
- 幼年异构体全部被救出——安娜等孩子安全
- 指挥官未被军方包围——行动自由度高

### 9.2 标准结局

**条件**：部分目标完成——岸防炮争夺成功或失败 + 通海阀设置可能被发现 + 撤离基本完成但有损失

**效果**：
- 格里芬有部分损失——少量人形被海水困住或在战斗中损坏

- M4A1出发前时间紧迫——告别仓促
- 逆向坍塌仍然发生——格里芬在混乱中失去M4A1
- 战后格里芬需要修复损失——但不严重

### 9.3 最差结局

**条件**：岸防炮争夺失败 + 通海阀设置被发现 + 指挥官被长时间包围 + 撤离严重延误

**效果**：

- 指挥官重伤——被军方手雷炸伤（左臂受伤流血）
- 幼年异构体可能未能全部救出
- M4A1在混乱中独自出发——没有告别
- 逆向坍塌仍然发生——格里芬在最糟糕的状态下失去M4A1

## 十、设计要点总结

### 10.1 本阶段的独特性

- **多线并行**：格里芬主力（地面）+ 忤逆（中层阻击）+ M4A1（底层追击）+ 404（护送）同时推进
- **真相揭示**：蝴蝶事件的完整真相在战斗间隙逐步揭示
- **不可逆结局**：M4A1的逆向坍塌是必然的——玩家无法阻止
- **情感高潮**：M4A1与M16A1的最终对峙、忤逆小队的绝望之战、叶戈尔的死亡
- **世界观揭示**：OGAS的本源、锡安的存在、威廉的真正身份

### 10.2 溃败线的特殊性

由于格里芬经历了溃败和重建：
- 格里芬战力可能不完整——部分人形仍在修复中
- M4A1的心理状态更极端——经历了被救走、性格崩溃、加入忤逆
- RO635/SOP-II可能不在——如果在第四阶段阵亡
- 格里芬对帕尔迪斯基的情报可能有限——准备不够充分
- 但核心事件（逆向坍塌、叶戈尔死亡、真相揭示）不受影响
