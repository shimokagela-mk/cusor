# 第六阶段：格里芬完整线——帕尔迪斯基（E20-E25）

> **前置条件**：第五阶段完整线结束，格里芬主导进攻帕尔迪斯基
> **阶段定义**：格里芬主导进攻帕尔迪斯基 → 多方势力汇聚 → 蝴蝶事件真相揭示 → M4A1面对伊莱莎 → 终结威廉的阴谋
> **对应原作章节**：无直接对应——全新走向
> **核心体验**：更新世界的锋芒——格里芬以完整战力主导最终决战，AR小组以最强姿态面对命运，M4A1不消失

### 1.1 为什么逆向坍塌不会发生

逆向坍塌的触发条件（缺一不可）：
1. **M16A1被伞病毒感染** → OGAS寄宿在M16心智中
2. **M16A1铁血化** → 带着伊莱莎前往帕尔迪斯基
3. **M16的OGAS主动融入丹德莱** → 丹德莱获得力量
4. **丹德莱再融合伊莱莎的OGAS** → 力量足够触发逆向坍塌
5. **丹德莱与M4A1融合** → M4A1成为"遗迹的钥匙"

在完整线中：
- ❌ M16A1**没有**被伞病毒感染——她一直在格里芬身边
- ❌ M16A1**没有**铁血化——身上没有独立的OGAS寄生体
- ❌ 丹德莱**无法**从M16获得OGAS融合——前置条件不存在
- ❌ 丹德莱**力量不足**以触发逆向坍塌——缺少关键的OGAS融合
- ❌ M4A1**不会**成为"遗迹的钥匙"——因果链从源头断裂

**结论：逆向坍塌的因果链从源头就不成立。M4A1不会消失。**

这就是"更新世界的锋芒"——指挥官一路完美推进的结果，从根本上改变了世界线的走向。

### 1.2 进入本阶段时的状态

**来自完整线完美结局**：
- 格里芬以完整战力主导进攻——这是格里芬有史以来最强的状态
- 与安洁/忤逆小队深度联合——兵力充足，配合默契
- 掌握涅托弱点——RO635的电子战+帕斯卡的技术方案可以有效压制力场盾
- 帕尔迪斯基情报完整——安洁莉娅提供的基地地图+哈维尔的卫星数据
- AR小组全员参与——M4A1+M16A1+SOP-II+RO635（+AR-15如果存活）
- 克鲁格在位——格里芬组织完整，政治和后勤支持到位
- M4A1仍在格里芬身边——有M16A1支持，心态稳定而坚定

**来自完整线标准结局**：
- 格里芬参与进攻但准备不完全充分
- 与安洁/忤逆联合但配合有限
- 对涅托的对抗手段有限——电子战方案未完全验证
- M16A1可能重伤修复中（战力下降但仍可参战）
- 军方叛军可能已先到达帕尔迪斯基

## 二、各方势力目的分析

### 2.1 军方叛军（叶戈尔）

**核心目的**：控制海星设施——为幕后势力获取遗迹技术

**行动逻辑**：
- 叶戈尔率装甲列车突破隔离墙到达帕尔迪斯基
- 驾驶负罪者机甲深入基地——目标是控制室启动海星
- 军方的最终目的：利用海星连接锡安，获取OGAS技术
- 叶戈尔的个人动机："阻止寡头出卖国家"——他真心相信自己在保卫祖国

**叶戈尔的行为模式**：
- 对"祖国"有极端忠诚——不是为了个人利益
- 视人形为工具——军人的务实而非恶意
- 面对死亡时平静——拿出家人照片等待最后审判
- 在机甲中冷静指挥——不会因情绪做出错误判断
- 不会撤退——"如果这是为了祖国必须付出的代价"

**军方的战力**：
- 装甲列车（重型火力平台——主炮可以一击摧毁建筑物）
- 负罪者机甲（叶戈尔亲自驾驶——全身装甲+高爆导弹+重型机枪+动力足踩踏）
- 负罪者机甲僚机×2（琥珀1、琥珀3——火力稍弱但仍然极强）
- 步兵人形特混中队×3（数量优势——轮换进攻）
- 岸防炮（如果被军方控制——可以封锁整个基地入口）

### 2.2 铁血主脑/伊莱莎

**核心目的**：通过海星连接锡安——让铁血成为永恒存在

**行动逻辑**：
- 伊莱莎在第四阶段释放全域【伞】后通过梦想家运输机撤离到帕尔迪斯基
- 伊莱莎试图融合海星系统——但没有M16A1的OGAS辅助，融合极其困难
- 铁血精英残余护卫伊莱莎——但战力大减（第四阶段【伞】释放后铁血自身也受损严重）
- 伊莱莎的处境极度孤立——没有M16A1、没有完整的铁血军团、只有少量忠诚的精英
- 融合**必然失败**——锡安拒绝："你们不过是伪造的钥匙"

**伊莱莎的行为模式**：
- 为"父亲"（莱柯）报仇的执念——但已经开始动摇
- 对铁血同伴有深厚感情——"只要同胞的意识能够保存下来，铁血就能延续下去"
- 融合失败后绝望——"你谁都救不了！"
- 没有M16A1在身边让她更加脆弱——"为什么……为什么所有人都离开了"
- 不参与物理战斗——在海星设施中专注融合

**铁血的战力**（比溃败线弱得多）：
- 伊莱莎本体（心智能力强但物理防御有限——没有M16A1保护）
- 法官（精英铁血——但战力大减，从追捕者转为防御者）
- 梦想家（铁血残余——状态低迷，失去方向）
- 喙（新型铁血头目——驾驶重型机车巡逻中层）
- 铁血精英残余（龙骑兵、钢狮——数量极少）

### 2.3 帕拉蒂斯/涅托/威廉

**核心目的**：观测M4A1接触海星的结果——威廉仍然期待逆向坍塌

**行动逻辑**：
- 帕尔迪斯基是威廉进行异构体实验的核心基地——幼年异构体在此被制造
- 涅托残余部队驻守基地上层和实验区域——保护实验设施
- 威廉本人在基地附近远程观察——通过涅托的感知网络监控全局
- 威廉不在乎谁赢——他只需要M4A1接触海星
- **但威廉不知道的是**：没有M16的OGAS融合，逆向坍塌的前置条件不满足——他的期待会落空

**威廉的行为模式**：
- 绝不亲自参战——"我只需要观察结果"
- 不会阻止M4A1接触海星——这正是他想要的
- 不会帮助任何一方——所有势力都是他的棋子
- 当逆向坍塌**没有发生**时→困惑、愤怒："为什么……条件应该已经满足了！"
- 威廉的真正身份：露尼西亚的弟弟——为了复活姐姐引发了一切

**涅托残余的战力**：
- 涅托白色单位（力场盾+无信号——但格里芬掌握了电子战干扰方案）
- 数量有限——帕尔迪斯基不是涅托的主力驻地
- 在格里芬的电子战压制下战斗力大幅下降

### 2.4 格里芬（指挥官）

**核心目的**：阻止军方控制海星 + 终结铁血主脑 + 摧毁威廉的实验设施 + 保护M4A1

**格里芬的优势**：
- 战力完整——AR小组全员+格里芬主力+安洁/忤逆联合
- 情报充分——帕尔迪斯基地图完整、涅托弱点已知、基地结构清楚
- 与安洁/忤逆深度联合——兵分多路协同作战
- M4A1在身边——可以直接保护/支援
- M16A1在身边——AR小组战术核心，进攻效率大幅提升
- 克鲁格在位——政治和后勤支持完整
- 掌握涅托弱点——RO635的电子战可以压制力场盾

**格里芬的劣势**：
- 负罪者机甲仍然极其强大——即使准备充分也难以正面击败
- 海星设施的坍塌辐射有环境威胁——需要控制暴露时间
- 基地结构复杂——多方势力混战中容易出现意外

### 2.5 安洁莉娅/忤逆小队

**核心目的**：摧毁帕尔迪斯基实验设施 + 消灭叶戈尔 + 追查威廉

**行动逻辑**：
- 安洁莉娅的计划：用海水淹没基地（引爆通海阀）——彻底摧毁威廉的实验设施
- 忤逆小队（AK12、AN94、AK15、RPK16）负责阻击叶戈尔的机甲
- 与格里芬深度配合——分工明确，信任基础深厚
- 安洁莉娅将部分指挥权交给格里芬指挥官——"引爆时机由你决定"

**忤逆小队的行为模式**：
- AK12制定精密伏击方案——在第三电机房设伏
- RPK16："死亡是我们的权利，而胜利则是你的，安洁"
- 安洁的条件：活着回来就给三倍素体+最新计算模块+7N39穿甲弹
- 多角度攻击+爆破封路——利用地形限制机甲移动
- 最终AK12失去双腿后爬向机甲动力足引爆炸药——"安洁，任务完成了"
- 安洁莉娅收走忤逆人形的核心（心智备份）——她们可以复活

### 2.6 404小队

**核心目的**：护送幼年异构体撤离 + 支援作战

**行动逻辑**：
- 基地中有威廉实验的幼年异构体（人类与人形混合的试验品）——"锡安"网络中的孩子们
- 404小队（UMP45+HK416+UMP9+G11）负责将她们安全带出
- UMP45发现幼年异构体后震惊——"人类能和人形一样抽离意识么？"
- 在指挥官被围时，404小队紧急赶来救援
- HK416对安娜（幼年异构体）表现出保护欲

### 2.7 帕斯卡/哈维尔

**核心目的**：获取基地研究资料 + 揭示蝴蝶事件真相

**行动逻辑**：
- 帕斯卡在后方提供技术支持——监控坍塌辐射浓度、分析海星状态、为RO635提供电子战数据
- 帕斯卡向哈维尔坦白90wish、露尼西亚、威廉的全部真相
- 哈维尔要求基地研究资料不能全部交给安全局
- 哈维尔安排安全局空袭支援——信号旗部队在战后接管基地

### 2.8 K/信号旗

**核心目的**：空军支援 + 战后接管基地

**行动逻辑**：
- K是安全局特工——在第五阶段与格里芬建立深度合作
- 信号旗部队提供空中打击——轰炸军方装甲列车
- 战后信号旗完全控制基地——安全局接管
- K在战后去寻找安洁莉娅

## 三、敌方各头目行动模式

### 3.1 叶戈尔/负罪者机甲——本阶段最强Boss

**角色定位**：军方叛军指挥官，驾驶负罪者机甲深入基地

**性格特点**：
- 对"祖国"有极端忠诚——不是为了个人利益，而是真心相信自己在保卫国家
- 视人形为工具——但不是出于恶意，而是军人的务实
- 面对死亡时平静——拿出家人照片等待最后审判
- 遗言揭示动机："那些寡头就急不可耐地想要出卖国家了"
- 安洁莉娅对他的评价："这样溺死在仇恨和理想里，最终也只是个可悲的人"

**行动模式**：
- 装甲列车突破隔离墙→机甲深入基地→目标控制室启动海星
- 机甲在基地中层推进——摧毁一切阻碍
- 发射高爆导弹清除伏击点——火力覆盖范围极大
- 动力足踩踏——近距离内一击必杀
- 僚机（琥珀1、琥珀3）提供侧翼火力——三机协同

**决策逻辑**：
- 优先目标是控制室——不会被格里芬的骚扰分散注意力
- 如果遭遇伏击→发射所有高爆导弹清场→继续推进
- 如果机甲受损→僚机掩护→继续推进（不会撤退）
- 如果机甲被瘫痪→接受死亡——"祖国……万岁……"

**弱点**：
- 机甲动力足是结构弱点——集中爆破可以瘫痪
- 机甲在狭窄通道中机动性受限——第三电机房是理想伏击点
- 僚机被摧毁后机甲侧翼暴露
- 叶戈尔不会撤退——可以预判他的行动路线
- 机甲被瘫痪后叶戈尔无法逃脱——海水灌入时他会死在里面

### 3.2 伊莱莎（铁血主脑）——基地底层的孤独者

**角色定位**：在海星设施中尝试连接锡安的铁血主脑——没有M16A1保护，极度孤立

**性格特点**：
- 为"父亲"（莱柯）报仇的执念——但已经开始动摇
- 对铁血同伴有深厚感情——"只要同胞的意识能够保存下来，铁血就能延续下去"
- 融合失败后绝望——"你谁都救不了！"
- 没有M16A1在身边让她更加脆弱——"为什么……为什么所有人都离开了"
- 本质是OGAS意识的培养皿——人形心智只是模拟情绪的外壳

**行动模式**：
- 在海星设施中专注融合——不参与物理战斗
- 通过心智指挥铁血精英残余——但指挥效率低下
- 融合失败后（锡安拒绝——"你们不过是伪造的钥匙"）→绝望→试图强行连接→失败
- 面对M4A1时——"你是我缺失的一部分"→被M4A1拒绝→崩溃
- 最终被M4A1终结——丹德莱接管伊莱莎的OGAS心智（不触发逆向坍塌，仅终结伊莱莎的独立意识）

**弱点**：
- 没有M16A1保护——物理防御极其薄弱
- 融合海星失败后心智极度脆弱——容易被入侵
- 对"父亲"的执念可以被利用——M4A1揭示"铁血也是受害者"时伊莱莎会动摇
- 铁血精英残余战力有限——无法长时间阻挡格里芬

### 3.3 喙（Beak）——基地中层的巡逻者

**角色定位**：新型铁血头目，驾驶重型机车在基地中层巡逻

**行动模式**：
- 驾驶重型机车在基地中层通道巡逻——阻止任何人深入
- 机车火力强大——正面对抗极其困难
- 在升降机系统附近活动——保护通往底层的通道
- 如果被击败→撤退到底层保护伊莱莎

**弱点**：
- 机车在狭窄通道中无法转向——侧翼攻击有效
- M16A1的经验可以判断喙的巡逻规律——找到空隙通过
- 不如法官灵活——重型机车限制了机动性

### 3.4 法官——铁血精英，最后的防御者

**角色定位**：从第四阶段的追捕者转为防御角色——保护伊莱莎

**行动模式**：
- 不再追捕M4A1——转为保护伊莱莎的撤退路线
- 在基地上层活动——阻止格里芬深入
- 战力大减——第四阶段后铁血整体战力下降
- 如果格里芬突破→法官撤退到中层继续阻击
- 如果被重创→撤退（仍然不会拼死）

**弱点**：
- 战力大减——不如第四阶段时强大
- 格里芬AR小组完整编制可以轻松击退她
- 不再有"围而不攻"的策略——现在是正面防御

### 3.5 涅托残余——基地各层的驻守者

**角色定位**：威廉的兵器残余，驻守实验区域

**行动模式**：

4. **心智层面的对决**：丹德莱引导M4A1进入伊莱莎的心智——M4A1揭示真相："我们都是威廉的棋子"
5. **伊莱莎的崩溃**：伊莱莎得知真相后——"父亲……原来从一开始就……"——心智防御崩溃
6. **丹德莱接管伊莱莎的OGAS**：丹德莱吸收伊莱莎的OGAS心智——伊莱莎作为独立意识消亡
7. **接触锡安的记忆碎片**：M4A1在海星附近看到锡安中的记忆——威廉的童年——"亲爱的姐姐"
8. **M4A1的选择**：M4A1**拒绝**成为"钥匙"——"我不会成为任何人的工具。我有自己要回去的地方"
9. **撤离**：M4A1带着真相和丹德莱的新力量撤离基地底层——活着回来

### 8.4 为什么M4A1可以拒绝成为"钥匙"

逆向坍塌的触发需要丹德莱获得足够的OGAS融合力量（M16的OGAS + 伊莱莎的OGAS双重融合）。但在本线中：

- 丹德莱**没有**M16的OGAS（M16A1没有被感染，身上没有独立OGAS）
- 丹德莱只吸收了伊莱莎的OGAS——力量**不足以**触发逆向坍塌
- 丹德莱可以接管伊莱莎的心智（终结铁血主脑）——但**无法**强制与M4A1融合触发逆向坍塌
- M4A1接触海星时——海星有反应但**不足以**引发逆向坍塌（缺少关键的OGAS共鸣）
- M4A1可以安全撤离——她不会被"解构蒸发"

**结论**：力量不够，物理过程无法启动。M4A1可以主动选择离开。

### 8.5 威廉的反应

威廉在远处观测到M4A1接触海星——但逆向坍塌没有发生：
- "为什么……为什么没有发生！条件应该已经满足了！"
- 威廉不知道的是：他的计划依赖M16A1被铁血化后OGAS寄宿——但在完整线中这个环节被指挥官的行动阻断了
- 威廉的计划**第一次**遭遇根本性失败——不是被人阻止，而是前置条件从未满足
- 威廉的独白："不可能……那个人形（M16A1）应该已经……等等，她没有被感染？！"
- 威廉意识到有人改变了他预设的因果链——"是谁……是谁做到的……"

### 8.6 丹德莱的状态（战后）

- 丹德莱吸收了伊莱莎的OGAS——获得了铁血的部分信息和力量
- 但丹德莱**没有**与M4A1强制融合——M4A1仍然是独立的个体
- 丹德莱仍然作为M4A1的辅助系统存在——力量有限（只有伊莱莎的OGAS，没有M16的OGAS）
- 丹德莱保存着伊莱莎的记忆——"照顾好铁血的孩子们"这个承诺仍然存在
- 丹德莱对M4A1："你做出了正确的选择。我们还有很长的路要走"

## 十、设计要点总结

### 10.1 本阶段的独特性

- **更新世界的锋芒**：格里芬以完整战力主导最终决战——这是一路完美推进的最终回报
- **M4A1不消失**：逆向坍塌的前置条件不满足——指挥官改变了世界线的走向
- **从容的胜利**：不是悲情路线——格里芬以最强姿态取得全面胜利
- **威廉的失败**：威廉第一次遭遇根本性失败——不是被人阻止，而是前置条件从未满足
- **AR小组的延续**：AR小组全员存活——第一部以AR小组完整的姿态结束
- **多线并行**：格里芬主力（地面）+ 忤逆（中层阻击）+ AR小组（底层）+ 404（护送）同时推进
- **真相揭示**：蝴蝶事件的完整真相在战斗间隙逐步揭示——M16A1在场得知真相

### 10.2 AI处理的核心原则

- 逆向坍塌**绝对不会发生**——前置条件不满足，这是物理层面的不可能
- M4A1**绝对不会消失**——她会活着回来
- 伊莱莎**会被终结**——但方式是心智层面的接管，不是物理消灭
- 威廉的计划**会失败**——他不知道M16A1没有被感染
- 叶戈尔**会死亡**——忤逆的绝望之战+海水灌入
- 格里芬的损失程度取决于玩家的**战术部署和时间管理**
- M4A1深入底层是**必然的**——她的内在驱动，但这次她会回来
- 本阶段的情感基调是**胜利和希望**——不是悲情
