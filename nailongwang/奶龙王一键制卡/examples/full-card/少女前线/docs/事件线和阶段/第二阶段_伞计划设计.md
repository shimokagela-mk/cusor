# 第二阶段：伞计划 - 分支路由

> **阶段定义**：AR小队全员归队 → 第二阶段结束
> **对应原作章节**：第五章（火种）~ 第六章（彗星）+ 魔方行动+

---

## 分支判定条件

第二阶段的完整设计取决于**第一阶段的结果**——核心分歧点是：**AR-15是否被植入了【伞】入侵程序**。

### 判定逻辑

```
if 第一阶段中AR-15被猎手逼入铁血防线（被植入伞）:
    → 使用「第二阶段_有伞分支.md」
else:
    → 使用「第二阶段_无伞分支.md」
```

### 分支文件

| 条件 | 文件 | 核心体验 |
|------|------|----------|
| AR-15被植入伞（标准走向） | [第二阶段_有伞分支.md](./第二阶段_有伞分支.md) | 信任与背叛的两难 |
| AR-15没有被植入伞 | [第二阶段_无伞分支.md](./第二阶段_无伞分支.md) | 正面对抗铁血围猎 |

---

## 两个分支的核心区别

| 维度 | 有伞分支 | 无伞分支 |
|------|----------|----------|
| **核心体验** | 信任与背叛的两难 | 正面对抗铁血围猎 |
| **时间压力来源** | AR-15体内程序持续泄露情报 | 梦想家的侦察逐步逼近 |
| **AR-15的角色** | 定时炸弹/自我牺牲者 | 正常战力/保护者 |
| **铁血情报来源** | AR-15内应（精准） | 梦想家空中侦察（需要时间） |
| **格里芬通讯** | 被AR-15屏蔽网干扰 | 正常运作 |
| **炼金术士优势** | 屏蔽网困住格里芬人形 | 常规伏击，无屏蔽网 |
| **铁血主脑定位精度** | 高（通过AR-15获取） | 低（通过外部侦察） |
| **结束标志** | AR-15牺牲/存活 | 铁血主脑首次行动成败 |
| **难度** | 极高（内外夹击） | 中高（正面对抗） |

---

## 共同要素（两个分支都不变）

以下内容在两个分支中完全相同，不需要重复判断：

1. **404小队线**：在S06区执行窃取干扰器任务，被铁血利用完成程序植入
2. **铁血主脑的核心驱动**：想接触M4A1，想知道"M4A1到底是谁"
3. **代理人暗线**：利用404接触干扰器完成新的【伞】程序植入
4. **铁血内部权力博弈**：梦想家对破坏者、代理人对衔尾蛇
5. **克鲁格的考验**：考验指挥官的决策能力
6. **帕斯卡的关注**：AR小组心智云图的特殊性
7. **敌人池**：Boss和普通敌人列表相同

## 其他第一阶段结果的影响

除了AR-15是否被植入伞这个核心分歧外，还有其他第一阶段结果会影响第二阶段：

| 第一阶段结果 | 对第二阶段的影响 | 影响哪个分支 |
|--------------|------------------|--------------|
| M4A1在第一阶段被捕过 | 铁血已获取部分3号安全屋资料，不需要侦察也能定位据点 | 两个分支都受影响——铁血突袭更快 |
| 全员完好归队+情报完整 | 格里芬有更多准备时间 | 有伞分支：可能提前发现AR-15异常。无伞分支：有更多时间部署防御 |
| 猎手在第一阶段存活 | 猎手可能在第二阶段再次出现 | 两个分支都受影响——铁血多一个可用头目 |
