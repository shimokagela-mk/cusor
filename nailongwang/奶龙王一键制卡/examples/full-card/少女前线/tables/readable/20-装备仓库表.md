## 说明

- 记录玩家拥有的装备实例。每行是一件具体装备，`row_id` 是装备实例唯一身份。
- 装备名称、类别、星级、槽位和适配规则从装备图鉴表读取。
- stats 是当前属性，不写回人形仓库表。

## 更新规则

- 初始化: 当前内容可包含初始装备实例，也可为空。
- 更新: 禁止。装备强化、校准、锁定由前端维护。
- 插入: 禁止。新增装备实例由装备制造或维护者写入。
- 删除: 禁止。分解装备由前端处理。

## DDL

```sql
CREATE TABLE equipment_warehouse ( -- 装备仓库表
  row_id INTEGER PRIMARY KEY, -- 行号
  equipment_id TEXT NOT NULL, -- 装备ID
  base_stats TEXT NOT NULL, -- 实例基础属性
  stats TEXT NOT NULL, -- 实例当前属性
  level INTEGER NOT NULL DEFAULT 0, -- 强化等级
  calibration TEXT NOT NULL DEFAULT '', -- 校准记录
  exp INTEGER NOT NULL DEFAULT 0, -- 强化经验
  locked TEXT NOT NULL DEFAULT '否' CHECK(locked IN ('是', '否')), -- 是否锁定
  acquired TEXT NOT NULL DEFAULT '是' CHECK(acquired IN ('是', '否')), -- 是否拥有
  source TEXT NOT NULL DEFAULT '' -- 来源
);
```
