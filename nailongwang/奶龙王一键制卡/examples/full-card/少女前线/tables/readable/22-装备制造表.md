## 说明

- 记录装备制造队列。装备制造不与人形建造表混用。
- 开始制造时即写入结果种子和结果装备 ID，领取时不重新抽取模板。

## 更新规则

- 初始化: 当前内容保持空表，由前端写入装备制造任务。
- 更新: 禁止。装备制造状态由前端维护。
- 插入: 禁止。新增装备制造任务由前端写入。
- 删除: 禁止。领取装备由前端删除队列。

## DDL

```sql
CREATE TABLE equipment_construction ( -- 装备制造表
  row_id INTEGER PRIMARY KEY, -- 行号
  start_time TEXT NOT NULL, -- 开始时间
  construction_time TEXT NOT NULL, -- 制造时间
  cost_manpower INTEGER NOT NULL DEFAULT 0, -- 消耗人力
  cost_ammo INTEGER NOT NULL DEFAULT 0, -- 消耗弹药
  cost_ration INTEGER NOT NULL DEFAULT 0, -- 消耗口粮
  cost_parts INTEGER NOT NULL DEFAULT 0, -- 消耗零件
  recipe_type TEXT NOT NULL DEFAULT '普通装备制造', -- 配方类型
  result_seed TEXT NOT NULL DEFAULT '', -- 结果种子
  result_equipment_id TEXT NOT NULL DEFAULT '', -- 结果装备ID
  candidate_pool_hash TEXT NOT NULL DEFAULT '' -- 候选池哈希
);
```
