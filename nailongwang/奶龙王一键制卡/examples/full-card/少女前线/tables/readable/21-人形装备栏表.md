## 说明

- 记录人形当前装备栏。每个人形同一槽位只能装备一件装备，同一装备实例不能被多人共用。
- 装备实例引用 `equipment_warehouse.row_id`，不使用业务字符串 ID。
- 前端写入前必须校验枪种、槽位和特定人形白名单。

## 更新规则

- 初始化: 当前内容可为空，由前端换装写入。
- 更新: 禁止。装备栏由前端维护。
- 插入: 禁止。装备关系由前端换装写入。
- 删除: 禁止。卸下装备由前端处理。

## DDL

```sql
CREATE TABLE tdoll_equipment ( -- 人形装备栏表
  row_id INTEGER PRIMARY KEY, -- 行号
  tdoll_name TEXT NOT NULL, -- 人形名称
  slot_type TEXT NOT NULL CHECK(slot_type IN ('配件', '弹匣', '人形', '特殊')), -- 槽位类型
  equipment_row_id INTEGER NOT NULL, -- 装备仓库行号
  UNIQUE(tdoll_name, slot_type),
  UNIQUE(equipment_row_id)
);
```
