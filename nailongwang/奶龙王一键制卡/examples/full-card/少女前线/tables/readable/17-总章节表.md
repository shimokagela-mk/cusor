## 说明

- 记录所有战役章节的解锁状态和章节类型。
- 本表是章节选择与章节解锁的唯一进度表。
- 当前所有已初始化战役均视为 `主线`，顺序按 `entries/609-619` 战役世界书文件顺序排列。
- `类型` 只能填写 `主线`、`支线`、`活动`。当前暂无活动章节和支线章节。
- `状态` 只能填写 `未开始`、`进行中`、`已完成`。
- 第一章 `急性期` 初始为 `进行中`，其他章节初始为 `未开始`。
- `进行中` 章节允许继续出击；`已完成` 章节不允许重复出击。
- 撤退或全灭不改变本表状态；章节完成由前端受控结算入口或维护者手动调整。
- 本表禁止填表 AI、地图生成 AI 和正文更新规则修改。只能由前端章节选择入口和胜利结算入口更新。
- 【列定义】
- 列1=章节名：战役章节名称，必须与世界书战役条目的章节名一致。
- 列2=类型：主线/支线/活动。
- 列3=状态：未开始/进行中/已完成。

## 更新规则

- 初始化: 按当前内容初始化所有战役章节；第一章为 `进行中`，其他章节为 `未开始`。
- 更新: 禁止 AI 更新。本表只能由前端章节选择入口将未开始章节改为进行中，或由前端 Boss 胜利结算入口将当前章节改为已完成；`终章` 不参与 Boss 胜利结算，进入后长期保持进行中。
- 插入: 禁止 AI 插入。新增章节只能由维护者同步新增世界书战役条目后手工维护。
- 删除: 禁止。章节行不得由 AI 删除。

## DDL

```sql
CREATE TABLE total_chapters ( -- 总章节表
  row_id INTEGER PRIMARY KEY, -- 行号，按世界书战役文件顺序排列
  chapter_name TEXT NOT NULL UNIQUE, -- 章节名
  chapter_type TEXT NOT NULL CHECK(chapter_type IN ('主线','支线','活动')), -- 类型
  chapter_status TEXT NOT NULL CHECK(chapter_status IN ('未开始','进行中','已完成')) -- 状态
);
```
