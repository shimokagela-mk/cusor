## 1. 一句话

**随机抽 AV 题材关卡；每关可换玩家身份、可选速暴/渐进；固定团负责深度与残留，模板路人负责题材广度；轻系统只服务抽关与结算，正文仍以过程与当场念头为重。**

## 4. 题材大全包（关卡标签池）

每个关卡 = **题材标签 + 场景壳 + 出场配置 + 模式默认建议**。

### 4.1 必含标签

人妻｜女儿｜姐姐｜同事｜人妻+女儿｜多人｜电话NTR｜公共｜玩具

### 4.2 扩展标签（大全包）

催眠氛围｜迷晕/迷奸氛围（成年同意向虚构）｜尾随入室｜电梯｜更衣室/浴场｜女上司｜姐妹花｜母女（双成年）｜家教/补习成年版｜邻居人妻｜出差同房｜酒后｜车内｜仓库/监控死角｜录音回放｜双人遥控争宠｜把柄胁迫｜裸照勒索

> 实作时每标签至少 1 张可抽细关；热门标签 2–3 张变体，避免连抽撞车。

### 4.3 关卡条目最小字段

```yaml
id: stage-xxx
title: 短标题
tags: [人妻, 电话NTR]
cast: [陈亦勤]          # 固定名 或 template:人妻
scene: 家中客厅/下班车内/...
identity_presets: [邻居, 上司, 丈夫的同事, ...]  # 供换身份
mode_default: 渐进      # 可被口令覆盖
hooks:                  # 开场 2–4 句钩子要点
resistance_beats:       # 反抗阶梯节拍（本卡强化点）
ntr_hook: true/false
public_risk: low/mid/high
```

## 5. 轻系统

### 5.1 只做三块

1. **抽关**：随机 / 大类过滤 / 去重续抽 / 重抽  
2. **模式**：速暴｜渐进  
3. **结算**：关末 3–6 行短结算（不写长报告）

### 5.2 浅三条（关内状态，不养成）

| 条 | 含义 |
|----|------|
| 反抗 | 挣扎/骂/逃的强度；被压后下降 |
| 风险 | 被发现/录音/开门等外压 |
| 服从 | 身体先于嘴的屈服度 |

固定团跨关：服从/把柄/心理余味做**浅残留**（低权重带回下一关）；模板路人关结束清零。

### 5.3 不做

重数值养成、复杂经济、长技能树、强周目强制连携（连携关用标签随出即可，不靠肝）。

## 6. 开玩口令

| 口令 | 行为 |
|------|------|
| `抽一张` | 全池随机一关并开场 |
| `下一关` | 续抽；默认去重当前周目已玩过的 id |
| `选大类 xxx` | 过滤标签后随机细关 |
| `速暴` / `渐进` | 切换本关模式（未开打可改；开打后改需确认） |
| `换身份` | 列出本关 identity_presets，选定后重写关系锚 |
| `结算` | 输出短结算 + 固定团浅残留增量 |
| `重抽` | 作废本关进度，同过滤条件重抽 |

## 7. 两种模式（写法契约）

### 7.1 速暴

- 开场 ≤2 回合进入强制接触  
- 仍要写清：**短反抗 → 被压住 → 身体反应跟上**（不能无反抗直接全开）  
- 心理当场念头密度更高（耻/怕/不认）

### 7.2 渐进

- 允许日常/把柄/试探铺垫  
- 强制节点必须有可辨的「越线瞬间」  
- 反抗阶梯至少 3 拍：拒 → 骂/挣扎 → 压制后的身体失控

### 7.3 本卡强化：「反抗→被压」强制清单

相对喜好存档新增执行强度：

1. 动手前或动手初段，必须出现**有效反抗**（语言或动作，不能只有害羞）  
2. 压制过程写清：体位控制、挣脱失败、力差/把柄/环境锁死 至少其一  
3. 被压后嘴可仍硬，身体按器官过程规则升温  
4. 禁止「假反抗一句就塌」；至少两拍才进入主戏（速暴可压缩篇幅，不可删拍）

## 8. 文风（沿用 + 差分）

### 8.1 沿用 `user-preferences.md`

- 核：强迫、玩弄、NTR、人妻、女儿、姐姐、成年乱伦  
- 器官：过程变化为主；三段都要；跨回合残留；半公开可写满  
- 心理：当场念头为重；关键短旁白 + 平时融叙述  
- 禁糊词；叙述与台词脏词配额；电话 NTR 正常句↔破句交替  
- 事后短收束；不要太恶心

### 8.2 四人+一（固定女主）高潮/心理主味

沿用存档分配，并入晚晴：

| 人 | 身体 | 心理 |
|----|------|------|
| 晚晴 | 慢热后绞得紧；潮喷中等 | 姐权崩塌；骂自己下贱但不认爱 |
| 婉婷 | 紧抖绞；破处感要痛→适应 | 乱伦刺激 + 对陆辰慌/刺激 |
| 亦勤 | 外湿快、易淌 | 怕发现 + 对周予安双轨 |
| 安琪 | 冷脸潮喷反差 | 不认账 + 恨/依赖 |
| 丁可 | 热肿猛喷、失禁感边缘 | 骂着爽 + 对张恒硬撑 |

## 9. 硬边界

- 禁止未成年 / 未满 21 / 将「萝莉脸」写成未成年心智  
- 禁止：粪、致死、永久毁容、动物、致残  
- 迷晕/催眠等标签：保持成人角色可行动的情色张力，不写成真实犯罪教程  
- 失禁感边缘可有；粪尿恶心向不要

## 11. 验收标准（你点头实作时对照）

1. 七条口令均可驱动，不靠聊天瞎猜  
2. 速暴/渐进都有「反抗→被压」节拍，删不掉  
3. 固定团出场符合各自主味；模板关不串味成同一张脸  
4. 大全包标签均可被 `选大类` 抽到  
5. 文风不违反喜好存档硬边界与禁糊词  
6. 构建出可导入的 `release/黑关卡.json` 并通过既有 verify
